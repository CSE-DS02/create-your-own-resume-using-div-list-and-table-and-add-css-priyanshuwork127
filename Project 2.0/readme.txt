SHOPVILLE is a responsive multi-page e-commerce website created using HTML+CSS.
This project focuses on building a clean layout, navigation between pages, and product detail pages similer to real online platforms.
Features
->Responsive navigation bar
->Separate pages for:
   1.Top deals
   2.Electronics
   3.Mobiles
   4.Fashions
->Product card with images and buttons
->Responsive layout for different screen
->External CSS used for consisted styling

NOTE:Also adding a demo video of website in assets


To view the website clone the git and open the "index.html" in any browser
